BASTION MCTRADE v1.1.1 — COLORES HEX Y DEGRADADOS

Compatible con Purpur 1.21.11 / Java 21.

En plugins/BastionMCTrade/messages.yml puedes usar:

  menu:
    accept:
      name: '&#BFFFAF&lAceptar'

O un degradado automático:
  name: '<gradient:#BFFFAF:#55FF55>Aceptar</gradient>'

También admite códigos normales &a &6 &l y formato largo &x&B&F&F&F&A&F.
Esto funciona en títulos, nombres de botones, lore y mensajes.

Tras editar messages.yml ejecuta /bastiontrade reload.

COMO COMPILAR:
Sube pom.xml, src/ y .github/ al repositorio, manteniendo las carpetas.
GitHub Actions > Compilar BastionMCTrade > Artifacts > BastionMCTrade-JAR.

NOTA: Esta es una actualización del código fuente; prueba en un servidor de pruebas
antes de intercambiar objetos valiosos. Para colores HEX usa &#RRGGBB.
